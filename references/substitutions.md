# 치환 목록

`SKILL.md`의 문체 규칙(12, 20, 21, 22번)에 해당하는 사례표이며, `scripts/lint.py`가 이 표를 읽어 검사한다.

표의 세 번째 열은 검사 등급이다.

- `error`: 규칙 위반으로 확정한다. 문맥과 무관하게 고친다.
- `review`: 문맥에 따라 정상 용법일 수 있다. `lint.py --review`에서만 보고하며 작성자가 판단한다.

이 표는 예시이며 목록이 아니다. 표에 없다고 통과가 아니므로 `SKILL.md`의 판정법(20번 주어 치환, 21번 목적어 치환)을 함께 적용한다.

|---|---|---|

| 되게 | 매우 | error |
| 엄청 | 매우 | error |

| 좀 | (삭제) | review |
| 너무 | 과도하게 | review |

## 의인화와 물리 은유

판정법은 주어를 사람이나 사물로 바꿔 자연스러운지 보는 것이다. 개념의 이름(예: 드리프트, 병목)은 비유가 아니므로 유지하고 서술만 고친다.

| 쓰지 않는다 | 쓴다 | 검사 |
|---|---|---|
| 큐가 밀린다 | 큐에 적체가 발생한다 | error |
| 값이 튄다 | 값에 이상치가 발생한다 | error |
| 갉아먹 | 저하시킨다 | error |
| 세션이 살아 있다 | 세션이 유지된다 | error |
| 서버가 죽는다 | 서버가 중단된다 | error |
| 서버가 죽었 | 서버가 중단되었 | error |
| 문서가 다룬다 | 문서는 ...로 한정한다 | review |
| 살아 있 | 유지되 | review |
| 싸운다 | 충돌한다 | review |

## 과장과 위협

소요와 위험은 사실로 적는다.

| 쓰지 않는다 | 쓴다 | 검사 |
|---|---|---|
| 하루면 끝난다 | (삭제 또는 선행 조건 명시) | error |
| 유일한 답 | 필요한 조치 | error |
| 회복이 어려워진다 | 착수 시점을 먼저 확정한다 | review |
| 일정이 위험하다 | 일정 순연 가능성과 대응을 명시 | review |
| 반드시 성공 | (근거 제시) | review |

## 의미역이 넓은 동사

판정법은 그 동사에 목적어를 바꿔 끼워 보는 것이다. 데이터, 업무, 권한이 모두 자연스럽게 붙으면 의미역이 넓다. 계약, 업무분장, 결정 사항에서는 좁은 동사를 쓴다.

| 쓰지 않는다 | 쓴다 | 검사 |
|---|---|---|
| 넘긴다 | 전달한다, 이관한다, 위임한다 | review |
| 늦춘다 | 순연한다, 유예한다 | review |
| 적는다 | 명시한다, 기재한다, 기록한다 | review |
| 나온다 | 도출된다, 산출된다, 확정된다 | review |
| 뺀다 | 제외한다, 차감한다 | review |
| 붙인다 | 부착한다, 부기한다, 첨부한다 | review |
| 잡는다 | 검출한다, 산정한다, 고정한다 | review |
| 막는다 | 차단한다, 방지한다 | review |
| 갈린다 | 분기한다, 분리된다 | review |
| 지운다 | 삭제한다, 제거한다 | review |
